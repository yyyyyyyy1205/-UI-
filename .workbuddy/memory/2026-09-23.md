## 代码复查（回答"关键代码及作用"时发现的问题）
- **搜索筛选失效（真 bug）**：父组件用 `v-model:search-key="searchKey"`，经 @vue/compiler-sfc 编译确认生成 `"search-key"` prop + `"onUpdate:searchKey"` 监听；但 `SearchArea.vue` 声明的是 `modelValue` prop、emit 的是 `update:modelValue`。两边不匹配 → searchKey 永远为空 → `filterSkill` 永远返回全部技能（输入框自身能打字，但列表不过滤）。修法：子组件改成 `defineProps(["searchKey"])` + `emit("update:searchKey", ...)`。
- **暗色主题作用域不完整**：`--*` 变量定义在 App.vue 非 scoped 的 `<style>`（全局，正常），但 `.dark` 类只挂在 `.container` 上；TopHeader/Footer 在 container 之外 → 暗色模式下顶栏、页脚、body 仍是浅色。App.vue 里 `.dark html, .dark body` 是无效选择器（.container 不可能是 html/body 祖先）。
- **Teleport 丢 CSS 变量**：ProjectShow 的弹窗 teleport 到 body，变量改从 `:root` 解析 → 暗色模式下弹窗保持白底浅色。
- `HelloWorld.vue` 是 Vite 模板残留，无任何 import（死代码）。
- 关键代码结构：App.vue 是唯一数据源（isDark/info/skillArr/searchKey/showDetail + computed filterSkill），子组件全靠 props 下传 / emit 上抛；InfoEdit 用本地副本 + watch 不直接改 props；BaseCard 三个具名插槽；ProjectShow 用 Teleport 做弹窗。
- 验证技巧：不确定组件 v-model 生成的 prop/事件名时，用 `node -e` 调 `node_modules/@vue/compiler-sfc/dist/compiler-sfc.cjs.js` 的 compileTemplate 直接看生成代码，比跑浏览器快得多。
